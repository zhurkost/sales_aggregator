# Автопост 0.4

Помощник размещения объявлений в Беларуси: одна карточка, категории, фотографии, личный кабинет и очередь площадок.

Основной сайт: **https://87.199.205.227**. Перед профилями приложения остаётся общий пароль закрытого MVP. Доступы находятся у владельца вне репозитория.

## Возможности

- Профили с логином и паролем, без почты и подтверждений. Карточки изолированы, пароли хешируются. Восстановление пароля пока отсутствует.
- Нулевой шаг: описание → одна категория Автопоста → просмотр/исправление категорий площадок → карточка. Фото принимаются сразу, но в ИИ не отправляются.
- Единый справочник 315 категорий: 220 узлов публичного дерева Kufar и 215 разделов Onlíner, без отдельных первичных категорий «Барахолка Onlíner». Полный каталог Flagma (8881 подраздел) доступен для поиска и исправлений; подтверждённые совпадения связаны автоматически. Автомобили и запчасти имеют специальные поля; остальные товары — общую карточку. Это не полное покрытие всех площадок РБ.
- DeepSeek через OpenRouter, серверный ключ. Без ключа доступны локальный поиск по словам и ручная карточка.
- Фотографии: загрузка файлов, перетаскивание или вставка изображения/скриншота через Ctrl+V (⌘V на Mac) в редакторе. До 12 фото, JPG/PNG/WebP до 20 МБ; вставленные снимки сжимаются и сохраняются в карточке. Обычная вставка текста не перехватывается.
- Серверный кабинет: объявления, фото, история изменений, задания, ссылки и локальный архив. Архив не снимает объявление с площадки.
- Импорт XLSX, CSV, TSV, JSON до 500 строк: сопоставление колонок, предпросмотр, проверка повторов. OEM хранится строкой. Старый XLS сохранить как XLSX.
- Пакетная привязка фото: колонка `photos` с именами через `|` или файлы `externalId_1.jpg`, `externalId_2.jpg`. Ссылки сохраняются для официальной выгрузки; автоматически не скачиваются.
- Браузерная очередь до 20 карточек: одна активная карточка на площадку. После сохранения ссылки или пропуска запускается следующая. Есть пауза и продолжение.
- Экспорт CSV и XLSX для Flagma по официальным колонкам. Конечный подраздел берётся из категории карточки, ручное переопределение необязательно; объявления выгружаются неактивными. Первое фото по публичной HTTPS-ссылке включается, если дано в таблице.
- Перенос двух текущих черновиков предыдущей версии из этого браузера: «Мои объявления → Перенести старые черновики». Старая история заданий не мигрируется; исходные данные не удаляются.

## Расширение 0.4.1

Скачать ZIP на сайте, распаковать и загрузить папку в `chrome://extensions` / `edge://extensions` с режимом разработчика. При обновлении заменить файлы и перезагрузить расширение и вкладки. [Инструкция](extension/README.md).

В 0.4.1 устранён сбой запуска без `storage.local.setAccessLevel`: фото хранятся в закрытой IndexedDB расширения. Проверка связи дожидается запуска фоновой части и сообщает, на каком этапе прервалось соединение.

Одиночный запуск открывает все выбранные площадки через API вкладок. Kufar открывается сразу на `/ain/create`, сессию создаёт сайт. Для Onlíner используются форма Барахолки или автомобильный раздел, для Bamper — официальный вход в добавление. Остальные адаптеры ищут видимую кнопку подачи.

Для «видеокарты, 570» выбирается `computers.gpu`: Kufar 16010 + `computers_component_type=11`, Onlíner 286, Flagma «Видеокарты». Поправки площадок хранятся в карточке и передаются в одиночную и массовую очередь. Старые `onliner.*` ID читаются через таблицу совместимости.

Исправлены реальные поля Kufar, категория, вложенные характеристики, валюта и динамически появляющиеся элементы. Общий адаптер Bamper/Onlíner/других каналов поддерживает нативные поля и распространённые списки. ABW показывает карточку, автоматическое заполнение отключено до разрешения площадки.

**Граница проверки:** публичная форма Kufar исследована в браузере, её структура покрыта регрессионными тестами. Закрытые формы Bamper/Onlíner и полная подача под аккаунтом продавца не проверены. Фото Kufar недоступны до входа. Нераспознанные поля и неоднозначные варианты требуют выбора пользователя. Финальная отправка, CAPTCHA и оплата остаются на площадке.

Сохранённая ссылка — подтверждение пользователя, не проверенная публикация. Синхронизация модерации, снятие, редактирование опубликованных объявлений и платное поднятие пока не подключены.

## Официальные импорты

[Исследование и условия подключений](docs/integrations.md). Экспорт Flagma реализован; автоматическая отправка файла не подключена. KML Kufar и ночной CSV Bamper требуют партнёрского доступа и настройки аккаунта. Отметка в «Интеграциях» сохраняет сведения пользователя, но не активирует обмен. Для неподключённых каналов доступна очередь с подтверждением завершения каждого объявления.

## Запуск и проверки

Node.js 22.18+:

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. В Windows есть `start.ps1`. Клиент/API слушают только loopback. Локальная БД: `work/local-data/workspace.sqlite`, исключена из Git.

ИИ настраивается в игнорируемом `.dev.vars`: `AI_API_KEY`, `AI_PROVIDER=openrouter`, `AI_MODEL=deepseek/deepseek-v4.1-flash-1017`. Windows-лаунчер умеет прочитать предоставленный владельцем `../openrouter token.txt`. Ключ не включается в клиент.

```sh
npm run typecheck
npm test
npm run package:vps
```

`npm run build` сохраняет совместимость сборки Sites, но API профилей и кабинета реализован для VPS. Ранняя опубликованная версия Sites этим релизом не обновляется.

## Устройство и данные

- React/Vite: `components/workspace-ui.tsx`, `app/page.tsx`; модели — `lib/`; категории — `data/taxonomy.json`.
- Node.js со встроенным SQLite: `vps/server.mjs`, `vps/workspace.mjs`. Npm-пакеты на сервере не нужны.
- БД `/var/lib/autopost/workspace.sqlite` находится вне релизов. До 100 профилей, 500 карточек/профиль, 12 фото/карточку. Версии карточек защищают от одновременных правок.
- Расширение MV3 выдаёт данные только назначенной вкладке. Пароли, cookie и токены площадок не читает.
- Фото очереди хранятся отдельно в закрытом хранилище расширения: 64 МиБ на очередь, 3,25 МиБ/карточку. После завершения, очистки или двух часов удаляются. После перезапуска браузера оставшиеся фото удаляются при запуске расширения.
- ИИ получает исходный текст, включая телефон, если он есть в тексте. Фото не передаются. Запросы оплачиваются через OpenRouter.

Тесты покрывают доступ к профилям, сохранение после перезапуска, конфликт версий, импорт/фото, классификацию, все выбранные площадки, очередь, изоляцию вкладок, валюту и отложенные поля Kufar. Они не заменяют подачу в реальных аккаунтах.
