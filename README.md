# Автопост

Одностраничный MVP помощника размещения автомобильных объявлений на площадках Беларуси. Одна карточка, фотографии, выбор каналов, браузерное заполнение и задания с честными статусами.

**Сайт:** https://autopost-belarus-mvp.sunlit-lemur-2753.chatgpt.site (доступ владельцу через ChatGPT).

## Запуск

Требуется Node.js 22.18+ и npm.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

Открыть http://127.0.0.1:5173. В Windows можно запустить `start.ps1`. Порт 5173 указан в разрешённых адресах расширения.

```sh
npm test
npm run typecheck
npm run build
```

Production-сборка: `npm start -- --port 5173`. На Windows ограниченная песочница может запрещать дочерние процессы сборщика; используйте обычный локальный терминал с разрешениями на проект.

## Реализовано

- Свободный текст, локальный разбор без ИИ и редактирование карточки.
- Серверная интеграция DeepSeek/OpenRouter: `/api/analyze`. Основной серверный провайдер — OpenRouter, модель `deepseek/deepseek-v4.1-flash-1017`. Можно использовать личный ключ другого провайдера.
- До 12 JPG/PNG/WebP, уменьшение до 1600 px, сжатие, превью и выбор обложки.
- Черновик с фотографиями и история до 30 заданий в IndexedDB браузера.
- Каталог av.by, Kufar, Onlíner, ABW, Flagma и Дрома; первичные источники и ограничения в интерфейсе.
- Проверка года, цены, пробега, контакта +375, VIN, фото и согласия перед передачей.
- Экспорт текста/JSON и задания для выбранных каналов.
- Chrome/Edge MV3: открытие av.by/Kufar, заполнение стандартных полей, фото и отчёт о пропусках.
- Статусы входа, CAPTCHA, ручного шага и проверки. Финальную подачу и оплату пользователь выполняет на площадке.

## ИИ и данные

В размещённой версии OpenRouter уже подключён серверным секретом `AI_API_KEY`. Интерфейс автоматически выбирает ИИ; ключ в браузер не передаётся. Для личного ключа открыть **Настройки ИИ → ИИ через API**, ввести ключ и выбрать провайдера/модель. Ключ находится только в памяти вкладки и передаётся серверу по HTTPS, затем фиксированному выбранному провайдеру. В исходники, IndexedDB, расширение и логи не сохраняется. После перезагрузки ключ нужно ввести снова. Запросы оплачиваются на стороне провайдера.

В запрос входит исходное описание: телефон, указанный в тексте, также будет передан ИИ. Фотографии и отдельно заполненные контакты не передаются. Для локального HTTP использовать только loopback, для внешнего размещения — HTTPS.

Реальный запрос через OpenRouter к DeepSeek V4.1 Flash успешно проверен 26.10.2026 на синтетическом описании: марка, год, цена/валюта извлечены, недостаток сохранён, телефон не выдуман. Также есть тесты с подменённым провайдером. Ошибки ключа, баланса, лимита, времени и формата показываются пользователю. Серверный ключ работает только для авторизованного посетителя закрытого сайта (либо локального loopback). Модель закреплена на сервере; базовый лимит — 10 запросов в минуту на пользователя в пределах экземпляра сервера. Перед открытием сайта всем нужны глобальные квоты и доступ пользователей.

Обычный OpenAI API оплачивается отдельно от ChatGPT/Codex. OpenAI также описывает использование плана ChatGPT для открытых локальных приложений — это отдельная OAuth-интеграция, не реализованная в данном MVP. Для платного/удалённого сервиса требуется отдельный путь согласования: https://developers.openai.com/siwc/token-sharing-open-source.

## Расширение

Скачать ZIP на странице, распаковать. В `chrome://extensions` / `edge://extensions` включить режим разработчика, нажать **Загрузить распакованное расширение**, выбрать папку с `manifest.json`. Обновить Автопост. Подробности: [extension/README.md](extension/README.md).

После создания заданий помощник откроет av.by/Kufar. Войти в аккаунт, открыть официальную форму подачи, выбрать категорию и нажать заполнение в панели Автопост. Помощник не переписывает непустые поля и не угадывает неоднозначные варианты. Несоответствующая полю валюта пропускается; пересчёта валют нет. Перед подачей проверить все поля и фотографии.

**Адаптеры beta, на авторизованных живых формах не проверены.** Нестандартные списки, отсутствующие поля, SMS, CAPTCHA и финальная отправка — ручные. Вход и регистрация на площадках не выполнялись. Полностью автоматическая публикация на всех площадках в этой версии не заявляется.

## Каналы

| Канал | Что реализовано |
|---|---|
| av.by, Kufar | Экспериментальный помощник стандартных форм, ручная финальная проверка |
| Onlíner, ABW, Flagma, Дром | Текст/JSON и переход на площадку |
| Партнёрские импорты | Исследованы для Kufar, Flagma, Дрома; генерация фидов и отправка не подключены |

ABW запрещает автоматическую подачу без разрешения, поэтому его адаптер выключен. Для импорта Kufar нужны партнёрский профиль, корректные справочники и доступные по сети фото. Неполный фид может удалить ранее размещённые записи. [Исследование рынка и первичные источники](docs/market-research.md).

## Архитектура

React 19 + TypeScript + Vinext/Vite, серверная функция ИИ, Cloudflare Worker для размещения, расширение MV3. Каталог: `lib/platforms.ts`; разбор и валидация: `lib/listing.ts`. Ключи не требуются для сборки. Серверные переменные: `AI_API_KEY` (секрет), `AI_PROVIDER=openrouter`, `AI_MODEL=deepseek/deepseek-v4.1-flash-1017`. Для локального режима `start.ps1` читает предоставленный файл OpenRouter в родительской папке и создаёт игнорируемый `.dev.vars`; ключ не выводится. Внешняя БД и серверное хранение фото не используются.

Черновик не синхронизируется между устройствами. История хранит текст и статусы, фотографии — только текущий черновик. В расширении один актуальный пакет на origin, до 12 фото/3,25 МиБ. Доступ к пакету прекращается через 2 часа; очистка спящего расширения отложена до пробуждения. Origins и целевые домены ограничены; передача требует пользовательского жеста.

## Проверка и следующий этап

Автоматические тесты: разбор, обязательные поля, границы и ошибки API, происхождение сообщений расширения, изоляция пакетов и жизненный цикл заданий. Типы и production-сборка проверены. Браузерная проверка внешнего вида не завершена: доступ к локальной странице отклонён системой разрешений. Тесты не заменяют испытание на авторизованных формах.

Далее: тестовые аккаунты и реальный автомобиль, точные адаптеры динамических списков, согласование интеграций с площадками, официальные импорты, подтверждённые статусы модерации/публикации/снятия.

Исследование на 26.10.2026. Посещаемость и охват не выдумывались; каталог не обещает исчерпывающего покрытия рынка. Полные копии сторонней документации не включены в репозиторий, первичные ссылки сохранены в исследовании.
