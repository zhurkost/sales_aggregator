# Помощник Автопост 0.9.20

Версия 0.9.20 переносит характеристики продажи поверх старого черновика Onliner, сохраняет ручные правки и продолжает заполнение после перехода пользователя к следующему шагу. На Domovita правка одного поля больше не блокирует остальные списки.

Версия 0.9.19 исправляет перенос адреса, условий сделки и характеристик при продаже квартир. Окончательную подачу подтверждает пользователь.

Расширение заполняет объявления о продаже и аренде квартир на Kufar, Onliner, Realt и Domovita по правилам, подготовленным сервером Автопоста. Автомобильные и товарные адаптеры, общая очередь, поиск цен и старый протокол удалены.

## Установка

Скачайте autopost-extension.zip с сайта Автопоста, распакуйте в постоянную папку. В chrome://extensions включите режим разработчика и загрузите распакованное расширение. При обновлении замените файлы и нажмите кнопку перезагрузки расширения; обновите вкладку Автопоста.

## Поведение

- Запуск — кнопкой из текущей формы Автопоста. Сервер проверяет данные и готовит инструкции без обращения к хранилищу объявлений.
- Обновление страницы, возврат через историю и прямой визит на площадку не запускают заполнение.
- «Остановить → Опубликовать» открывает новые формы и повторно переносит фотографии. Загрузка ждёт доступности поля, включая подтверждение телефона на Domovita.
- Переходы после заполнения, окончательная подача и платное продвижение выполняются пользователем. Автоматическая отправка удалена из кода.
- Onliner получает название населённого пункта: одна подсказка выбирается сразу, несколько — по полному совпадению без учёта регистра. Kufar получает очищенный адрес. Kufar, Realt и Domovita выбирают первую доступную подсказку нужного типа, а если такой нет или тип не указан — первую доступную.
- Задания изолированы по сайту Автопоста, кабинету, карточке и вкладке площадки. Фотографии заданий хранятся временно в IndexedDB расширения, метаданные — в storage.session.

## Проверки

В 0.9.24 добавлена категория houses_long_term_rent. Domovita открывается в ветке
cottages/rent; на Realt дом, коттедж и дача выбираются по карточке. Правила выбора
категории компилируются сервером, расширение получает конкретные шаги. Kufar может
запрашивать адрес до показа типа сделки и для домов. Onliner использует скопированный
квартирный шаблон по указанию владельца проекта; отдельная категория домов там не
подтверждена. Ни один адаптер не нажимает «Далее» или окончательную отправку.

В 0.9.26 адресные подсказки ожидаются до 30 секунд: медленный ответ не закрывает
поиск из-за заполнения соседних контролов. Ручная правка сразу освобождает очередь.
Правило выбора подсказки (тип, затем первая) не изменено.

В 0.9.25 Kufar сообщает о необходимости входа, когда форма без авторизации не
показывает параметры сделки. После входа ожидание продолжается автоматически.
Серверный справочник домов исправляет переключатель мебели Realt и перенос
11 дополнительных опций Domovita по подтверждённым нативным кодам.

npm test запускает проверки сообщений, привязки к документу, повторных запусков, фото, полей и адресных подсказок. DOM-тесты не заменяют проверку актуальных авторизованных форм площадок; объявления тестами не публикуются.

В 0.9.9 восстановлен признак поддержки адресных подсказок в PING, необходимый для запуска из кабинета. Номер версии в интерфейсе берётся из manifest расширения.

В 0.9.10 скрытые вкладки ждут активации без расходования попыток заполнения. Ожидание появления формы не ограничивается счётчиком пустых проверок. Возврат во вкладку возобновляет автоматическое ожидание незаполненных полей, но не ручную паузу. Срок задания — 2 часа; остановка из кабинета, обновление и история по-прежнему запрещают заполнение.

В 0.9.11 запуск использует текущую форму и локальный счётчик изменений. Фото находятся в памяти страницы до передачи расширению. Поддержка нового контракта объявляется признаком rental-form-session.

В 0.9.15 исправлен выбор города в адресном меню Onliner при восстановлении старого города площадкой.

В 0.9.14 кабинет проверяет приоритет типа адресной подсказки по признаку rental-address-type-then-first.
