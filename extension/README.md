# Автопост: помощник браузера, beta 0.1.0

Расширение для настольных Chrome и Edge переносит подготовленное объявление в распознанные поля на **av.by** и **www.kufar.by**. Оно работает вместе со [страницей Автопоста](https://autopost-belarus-mvp.sunlit-lemur-2753.chatgpt.site).

**Статус: экспериментальный прототип. Работа с живыми формами площадок не проверена (not live-verified).** Проверены валидация, маршрутизация сообщений, ограничения адресов, изоляция вкладок и срок действия данных. Это не официальная API-интеграция с площадками; успешное автозаполнение конкретной формы пока не гарантируется.

## Установка

1. Распакуйте архив расширения в отдельную папку. Если используете исходники, нужная папка — `autopost/extension`, в ней лежит `manifest.json`.
2. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Edge.
3. Включите «Режим разработчика» и выберите «Загрузить распакованное расширение».
4. Выберите папку с `manifest.json`.
5. Обновите вкладку Автопоста. После каждого обновления или перезагрузки расширения также обновляйте вкладки Автопоста и площадок.

Дополнительная сборка и установка npm-пакетов не нужны. Минимальная версия Chromium — 112.

## Как пользоваться

1. Составьте объявление на странице Автопоста, загрузите фото и выберите av.by и/или Kufar.
2. Нажмите кнопку передачи в браузер. Расширение откроет главные страницы выбранных площадок в отдельных вкладках.
3. На каждой площадке самостоятельно откройте «Подать объявление», войдите в свой аккаунт и выберите категорию автомобиля.
4. Панель «Автопост» в правом нижнем углу попробует заполнить распознанную форму. После входа, выбора категории или перехода к следующему шагу нажмите в панели «Повторить заполнение».
5. Откройте список перенесённых и пропущенных полей. Существующие значения не перезаписываются. Проверьте цену, валюту, характеристики, телефон и загрузку фотографий; заполните пропуски вручную.
6. При капче пройдите её самостоятельно. Кнопку окончательной публикации нажимает пользователь на самой площадке.

«Скопировать текст» копирует только заголовок и описание. Полный набор характеристик и контактов доступен в раскрываемом блоке для ручного переноса по отдельным полям. Вставлять весь этот блок в описание не следует: у площадок есть отдельные поля контактов.

**«Перенесено полей» означает перенос значения в элементы формы, а не публикацию объявления. «Фото переданы полю» не подтверждает загрузку на сервер.** Статуса «Опубликовано» в расширении нет.

## Возможности и ограничения

- Допустимы только av.by и Kufar. ABW и Onlíner не имеют автоматических адаптеров: для них используйте ручную подачу.
- Адреса открытия зафиксированы в коде: `https://av.by/` и `https://www.kufar.by/`. Переданный приложением URL не используется. Прямые адреса форм подачи не подтверждены.
- Панель работает также в официальных авторазделах `https://cars.av.by` и `https://auto.kufar.by`. Остальные поддомены не разрешены; при переходе на них используйте ручное заполнение.
- Распознаются обычные `input`, `textarea` и `select` по имени, подписи или подсказке. Нестандартные выпадающие списки, редакторы, поля внутри iframe и закрытых Shadow DOM могут потребовать ручного ввода.
- Заполнение запускается только в форме с распознанным описанием и заголовком/ценой. Поисковые формы и формы входа не заполняются.
- Значения списков выбираются только при однозначном точном совпадении текста или известного варианта названия. Неоднозначные поля пропускаются.
- На Kufar цена переносится только при валюте BYN. Расширение не конвертирует валюту. На av.by цена переносится только при подтверждённом совпадении валюты поля; иначе её нужно ввести вручную.
- До 12 фото JPEG/PNG/WebP: не более 1 МиБ на файл и 3,25 МиБ суммарно. Фотографии должны быть подготовлены приложением заранее. Если единственное поле загрузки принимает один файл, переносится только одно фото, остальные нужно добавить вручную.
- В заполненное поле файлов фото не добавляются. После первой передачи повторная автоматическая передача для той же задачи отключена, чтобы не создавать дубли. Проверьте результат загрузки на площадке.
- Расширение не нажимает кнопки входа, согласий, оплаты, продвижения, отправки формы или публикации; не обходит и не решает капчу.

Условия и интерфейсы площадок могут меняться: [av.by](https://av.by/pages/user_agreement), [правила Kufar](https://www.kufar.by/docs/agreements-and-rules?pageId=rules), [официальная инструкция Kufar по подаче](https://helpcenter.kufar.by/knowledge_base/item/274990?sid=58788).

## Данные и разрешения

- Используются только разрешения `storage` и `tabs`. Второе нужно для создания вкладок и проверки текущего адреса перед отправкой статуса. Доступ ограничен адресами, указанными в `manifest.json`; разрешения на все сайты, cookies, сеть, удалённый код и `scripting` не запрашиваются.
- Объявление и фото хранятся в `chrome.storage.session`, не записываются в `storage.local` и не отправляются на отдельный сервер расширения. При передаче в форму они становятся доступны соответствующей площадке, которая может автоматически загружать выбранные файлы или сохранять черновик.
- Срок действия пакета — 2 часа. После этого данные не выдаются и не используются. Очистка выполняется при следующем обращении к расширению; открытая панель также запрашивает очистку при истечении срока. Если браузер приостановил вкладки и service worker, физическая очистка откладывается до их пробуждения. Завершение браузерной сессии очищает `storage.session`.
- Команда `CLEAR` немедленно удаляет пакет текущего источника и очищает панели. Уже внесённые в форму площадки данные команда не удаляет; при необходимости удалите их на площадке.
- Временное хранилище закрыто для прямого доступа content scripts. Данные конкретного объявления выдаются только созданной для него вкладке и только на назначенной площадке. Статусы возвращаются только исходному origin приложения.
- Телефон, VIN, фото, текст объявления и токены капчи не выводятся в журнал. Пароли, cookies и API-ключи расширение не читает и не запрашивает.

## Контракт страницы и расширения

Разрешённые источники:

```text
https://autopost-belarus-mvp.sunlit-lemur-2753.chatgpt.site
http://localhost:5173
http://127.0.0.1:5173
```

Все сообщения идут через `window.postMessage` в тот же origin. `RUN` необходимо отправлять непосредственно в обработчике пользовательского клика; данные и base64-фото подготовьте заранее. Один доверенный жест разрешает один запуск. У `requestId` и `batchId` допустимы латинские буквы, цифры, `_`, `.`, `:`, `-`, длина 1–120 символов.

```js
window.postMessage({
  source: 'autopost-app',
  type: 'RUN', // также PING, STATUS, CLEAR
  requestId: crypto.randomUUID(),
  payload: {
    batchId: crypto.randomUUID(),
    listing: {
      title: 'Volkswagen Golf, 2019',
      description: 'Описание, подтверждённое продавцом.',
      brand: 'Volkswagen', model: 'Golf', year: '2019',
      mileage: '90000', engine: '1.4', fuel: 'Бензин',
      transmission: 'Автомат', body: 'Хэтчбек', drive: 'Передний',
      color: 'Серый', price: '45000', currency: 'BYN',
      city: 'Минск', phone: '', vin: '',
    },
    photos: [], // { name, type: 'image/jpeg' | 'image/png' | 'image/webp', dataUrl }
    platforms: [{ id: 'av' }, { id: 'kufar' }],
  },
}, location.origin);
```

ID `av`, `avby`, `av.by` обозначают av.by; `kufar`, `kufar.by` — Kufar. Ответ сохраняет переданный `platformId`. Один и тот же `batchId` не создаёт повторные вкладки; для нового запуска передайте новый ID. Новый пакет заменяет предыдущий пакет того же origin.

```js
// Ответ: source: 'autopost-extension', type: 'RESPONSE', requestId, payload
// PING:  { version: '0.1.0' }
// RUN/STATUS/CLEAR: { jobs: [{ platformId, status, message, tabId,
//                              filledFields, skippedFields, photosTransferred }] }
// Ошибка: { error: 'Описание ошибки', code: '...' }
// Обновление: source: 'autopost-extension', type: 'PROGRESS', payload: { jobs }
```

Возможные статусы: `authorization_required`, `captcha_required`, `review_required`, `manual_required`, `error`. Приложение должно проверять `event.source === window`, `event.origin === location.origin`, источник сообщения и ожидаемый `requestId`.

## Проверки разработчика

Из корня приложения:

```text
node --check extension/core.js
node --check extension/bridge.js
node --check extension/background.js
node --check extension/marketplace.js
node --test extension/tests/core.test.cjs extension/tests/background.test.cjs extension/tests/bridge.test.cjs
```

Тесты используют локальные подмены Chrome API и не выполняют публикацию или обращения к площадкам. Перед объявлением стабильной версии необходимо вручную проверить реальные формы с аккаунтами пользователя: вход, категорию, точность всех полей, валюту, фото, капчу, многошаговую подачу и сохранение пользовательских исправлений.
