# Помощник Автопост 0.5.0

Для настольных Chrome/Edge. Основной сайт: https://87.199.205.227.

## Установка

1. Распаковать ZIP с сайта.
2. В `chrome://extensions` / `edge://extensions` включить режим разработчика.
3. Загрузить папку с `manifest.json`. При обновлении заменить файлы и перезагрузить расширение.
4. Обновить вкладки Автопоста и площадок. На сайте появится «Помощник подключён».

В версии 0.4.1 исправлен сбой регистрации фонового процесса в браузерах без `storage.local.setAccessLevel`. После обновления замените все файлы, включая новый `photo-store.js`. Перезагрузите расширение и вкладку сайта. Проверка на сайте различает отсутствие связи и сбой фоновой части; «service worker (неактивно)» между обращениями допустим.

Из исходников сначала выполнить `node scripts/package-extension.mjs`: он создаёт `taxonomy.js` и `attributes.js`. Минимальный Chromium — 112.

## Использование

Создайте профиль, опишите товар, подтвердите категорию, проверьте карточку, приложите фото и выберите площадки. Запуск открывает каждую выбранную площадку с отдельным заданием. Kufar открывается на `/ain/create`; session UUID создаёт сам сайт.

Войдите в аккаунты площадок. Помощник продолжает после входа и появления полей. Непустые значения не перезаписываются. Списки выбираются при точном совпадении; неоднозначные варианты остаются пользователю. Цена переносится после подтверждения валюты, пересчёта нет.

После подачи на площадке сохраните ссылку в панели Автопост. Ссылка появится в кабинете, очередь откроет следующую карточку. «Пропустить» также двигает очередь. Пауза/продолжение — в массовой загрузке.

## Покрытие

- Kufar: публичная форма исследована; категория, стандартные поля, чипы/списки, динамические поля и валюта. Фото доступны после входа. Есть тесты по структуре наблюдавшейся формы.
- Onlíner: проверена единая форма 211 разделов Барахолки. Отдельные поля цены BYN и краткого описания; характеристики товара попадают в основное описание. Автобарахолка отдельно не проверена.
- Bamper: проверена базовая форма запчастей после входа, имена полей, Select2 и переключатели валюты/состояния/наличия; все варианты 2000 деталей не проверены.
- av.by и Flagma: проверка формы заблокирована VPN (423 / смена страны). Дром: форма после входа не проверена.
- ABW: карточка и ссылка, без автозаполнения до разрешения площадки.

Финальную публикацию, оплату, вход и CAPTCHA выполняет пользователь. Используется обычная сессия площадки в браузере. Тамперманки не отменяет ограничения защищённых форм и партнёрского доступа.

«Заполнено полей» — перенос в форму. «Передано файлов» — передача полю; проверьте миниатюры. «Ссылка сохранена» — подтверждение пользователя, не модерации. Автоматического статуса «Опубликовано» нет.

## Данные

Разрешения: `tabs` — вкладки, `storage` — задания, `unlimitedStorage` — фото массовой очереди, `alarms` — очистка. Адреса площадок зафиксированы; произвольные URL не открываются.

Метаданные — `storage.session`, фото — отдельно в IndexedDB на origin расширения, недоступном content scripts. До 20 карточек/запуск, 30 пакетов, 12 фото/карточку, 1 МиБ/файл, 3,25 МиБ/карточку и 64 МиБ фото очереди. Приложение сжимает фото заранее.

Сеанс действует два часа. Фото удаляются после завершения всех площадок, очистки или истечения срока (проверка каждые пять минут). После перезапуска браузера оставшиеся фото очищаются при запуске расширения. Карточки профиля остаются на сервере.

Пароли, cookie, токены площадок и ключ ИИ не читаются. Данные выдаются только назначенной вкладке. Статусы изолированы по origin и профилю. Выход из профиля приостанавливает очередь.

## Поиск цен в 0.5.0

Кнопка поиска обращается только к публичной первой странице Kufar и Барахолки Onlíner, без cookie, входа и фоновых вкладок. Новые host_permissions разрешают запросы только к этим двум доменам. Перед поиском серверный ИИ проверяет название товара/услуги; неоднозначный текст требует уточнения. Цена запрашиваемая, не цена сделки; выборка и валюты показаны отдельно. Никаких обходов CAPTCHA, закрытых API или регулярного сбора. Кэш в памяти до пяти запросов на пять минут.

Карточка хранит необязательные характеристики из официального справочника Kufar и проверенных форм. Они добавляются к описанию; распознанные поля заполняются отдельно. Данные о покрытии и источниках: `data/form-audit.json`, `data/category-fields.json`.
