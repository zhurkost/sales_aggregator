# Помощник Автопост 0.9.9

Расширение заполняет объявления об аренде квартир на Kufar, Onliner, Realt и Domovita по правилам, подготовленным сервером Автопоста. Автомобильные и товарные адаптеры, общая очередь, поиск цен и старый протокол удалены.

## Установка

Скачайте autopost-extension.zip с сайта Автопоста, распакуйте в постоянную папку. В chrome://extensions включите режим разработчика и загрузите распакованное расширение. При обновлении замените файлы и нажмите кнопку перезагрузки расширения; обновите вкладку Автопоста.

## Поведение

- Запуск — кнопкой из сохранённой карточки Автопоста. Данные фотографий остаются в браузере; правила и ревизия карточки проверяются сервером.
- Обновление страницы, возврат через историю и прямой визит на площадку не запускают заполнение.
- «Остановить → Опубликовать» открывает новые формы и повторно переносит фотографии. Загрузка ждёт доступности поля, включая подтверждение телефона на Domovita.
- Переходы после заполнения, окончательная подача и платное продвижение выполняются пользователем. Автоматическая отправка удалена из кода.
- Onliner получает название населённого пункта: одна подсказка выбирается сразу, несколько — по полному совпадению без учёта регистра. Kufar получает очищенный адрес и выбирает первую подсказку.
- Задания изолированы по сайту Автопоста, кабинету, карточке и вкладке площадки. Фотографии заданий хранятся временно в IndexedDB расширения, метаданные — в storage.session.

## Проверки

npm test запускает проверки сообщений, привязки к документу, повторных запусков, фото, полей и адресных подсказок. DOM-тесты не заменяют проверку актуальных авторизованных форм площадок; объявления тестами не публикуются.

В 0.9.9 восстановлен признак поддержки адресных подсказок в PING, необходимый для запуска из кабинета. Номер версии в интерфейсе берётся из manifest расширения.
