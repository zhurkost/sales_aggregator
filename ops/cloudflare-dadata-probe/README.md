# Проверка DaData через Cloudflare Workers

Изолированный диагностический Worker, не подключённый к приложению Angular/Spring.
Он проверяет только фиксированный публичный адрес: «Минск проспект Независимости 11».
Произвольные запросы и URL не принимаются. Объявления и пользовательские данные не передаются.

## Результат 1 ноября 2026 года

Развёрнут в Cloudflare-аккаунте проекта как `autopost-dadata-probe`.
URL: `https://autopost-dadata-probe.zhurkost.workers.dev`.
Версия кода Worker: `e53e6180-1a19-41d9-b8e1-014f80f1c75f`.

| Проверка | Результат |
| --- | --- |
| GET `/health` | HTTP 200 |
| POST `/probe` без ключа | HTTP 401; DaData не вызывается |
| Компьютер → Cloudflare AMS → DaData | HTTP 200; полный запрос 828 мс, обращение к DaData 572 мс |
| VPS 87.199.205.227 → Cloudflare LHR → DaData | HTTP 200; полный запрос 636 мс, обращение к DaData 393 мс |

Оба реальных запроса вернули три подсказки с `country_iso_code=BY`:
«г Минск, пр-кт Независимости, д 11», «д 11А», «д 110».
Проверка с VPS выполнена 2026-11-01T17:55:00Z.
Это единичные замеры, не гарантия задержки или доступности.
Прямое HTTPS-соединение VPS с DaData ранее завершалось таймаутом TLS.

Основной сайт продолжает работать на VPS. Его адресные подсказки **ещё не переключены**
на Cloudflare: этот Worker служит только проверкой связности, а не рабочим API подсказок.

## Защита и повторный запуск

Три значения хранятся как Cloudflare Worker Secrets:

- `DADATA_API_KEY` — ключ DaData;
- `PROBE_TOKEN` — случайный ключ доступа к диагностике;
- `PROBE_EXPIRES_AT` — время автоматического прекращения проверок (ISO 8601).

Текущая проверка действует до 2026-11-02T17:54:24Z; после этого `/probe` вернёт 410.
Секретные значения не входят в код, Git, аргументы команд и отчёт.
Токен диагностики создавался в памяти на время проверки. Для повторного запуска
нужно установить новый токен и срок действия. Ключи загружаются через stdin команды
`wrangler secret bulk`, без промежуточного файла.

`POST /probe` требует `Authorization: Bearer <PROBE_TOKEN>`.
Используйте идентифицирующий сервис заголовок `User-Agent: Autopost-Network-Probe/1.0`:
Cloudflare отклонил стандартный Python User-Agent с ошибкой 1010 ещё до Worker.
Диагностика не разрешает CORS, не сохраняет запросы, не включает Worker Logs.
Таймаут обращения к DaData — 15 секунд, максимальный ответ — 256 KiB, повторов нет.
Перенаправления не выполняются: Workers поддерживает `redirect: manual`,
а ответ 3xx считается ошибкой. Это исключает отправку ключа другому серверу.

Из корня репозитория:

```sh
node --test ops/cloudflare-dadata-probe/worker.test.mjs
npx wrangler@4.156.0 deploy --config ops/cloudflare-dadata-probe/wrangler.jsonc
```

Никакие DNS-записи, маршруты основного сайта или настройки VPS этот deploy не меняет.

## Возможная рабочая интеграция

Сохранить Angular/Spring и базу на VPS. Добавить отдельный защищённый маршрут
VPS → Worker → DaData, а выбор адреса, проверки Беларуси, ограничения запросов,
изоляцию пользователей и кэш оставить в Spring. Браузер не должен получать
ключ DaData или ключ доступа к Worker. Для рабочего маршрута нужны ограниченный
контракт запроса, проверка входных данных и обработка ошибок; диагностический
`/probe` для этого не подходит.

Документация Cloudflare: https://developers.cloudflare.com/workers/configuration/secrets/
