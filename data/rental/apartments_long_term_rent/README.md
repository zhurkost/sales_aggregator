# Рабочие справочники долгосрочной аренды

Это комплект, используемый приложением. Он хранится в GitHub, проверяется CI и
включается в архив релиза. Сервер читает копию из установленного релиза.

| Путь | Назначение |
|---|---|
| [manifest.json](manifest.json) | Реестр активных файлов |
| [integration/apartments_long_term_rent_common.json](integration/apartments_long_term_rent_common.json) | Общие поля Автопоста |
| `<platform>/apartments_long_term_rent_<platform>.json` | Поля, варианты, ограничения и зависимости площадки |
| `runtime/preparation_<platform>.json` | **Активный маппинг и преобразования**, исполняемые сервером |
| `runtime/card.json` | Общие варианты, подписи, группировка и адресные зависимости карточки |
| `runtime/browser_<platform>.json` | Рецепт заполнения формы для расширения |

Отчёты, исследовательские маппинги и bindings лежат отдельно, в
[research/rental/apartments_long_term_rent/](../../../research/rental/apartments_long_term_rent/),
и сервером не читаются.

Площадки: `kufar`, `onliner`, `realt`, `domovita`. Исходные схемы пока версии 1.2:
факты находятся в `fill_rule`; переход на 2.1 выполняется явно. Наличие поля в схеме
не означает, что его заполнение в браузере уже автоматизировано.

Редактируйте активные планы согласованно со схемами и common. Контрольные суммы
`schema_hash` и `common_hash` — SHA-256 компактной JSON-сериализации Jackson,
не отформатированных байтов файла. Не восстанавливайте неоднозначное соответствие
названия ЖК Kufar двум кодам: оно исключено из активного плана, а исследовательский
mapping сохранён в `research/`.

После сборки из корня репозитория:

```sh
java -jar backend/target/autopost-api.jar --validate-rental-reference=data/rental/apartments_long_term_rent
```

`npm run dev` подключает этот каталог автоматически. Сборка релиза также запускает
валидатор. `RENTAL_REFERENCE_DIR` позволяет явно выбрать другой комплект.
Файлы не копируются в Angular assets и не раздаются nginx как статические файлы.
Сырые HAR, сессии, ключи и пользовательские черновики в этот каталог не входят.
