Границы: Беларусь; предложение длительной аренды жилого дома целиком. Включены коттедж/дача там, где они входят в доступную ветвь. Исключены посуточная аренда, комната/часть дома, «сниму», продажа.
Источник задания: сообщение пользователя в чате и явное подтверждение «Да, длительная аренда дома целиком». Отдельного parsing_input.txt для домов нет; согласно правилам его не создавали и существующие входные задания не меняли.
Этап A; контракт 2.1. Новая категория исследуется впервые. Реализация приложения и активный каталог категорий не изменены. Common/mapping не созданы: это отдельный этап B. Исходники квартир используются только как пример метода, не как доказательство полей домов.
Собраны определения полей, а не объявление. Файлы не загружались; телефон/код подтверждения не отправлялись; кнопки окончательной подачи, сохранения, оплаты и пакеты продвижения не использовались. На Domovita «Далее» не нажимали.
Наблюдение: обычный браузер Chromium, отдельный анонимный контекст, русский интерфейс; открывались только формы и необходимые справочные страницы. Дополнительно Onliner проверен в существующей авторизованной сессии Chrome. Доступные странице определения полей прочитаны из DOM/React props и ответа bootstrap, вызванного самой формой. Прямые запросы к GraphQL/sdapi и обход защиты не выполнялись.
Ограничение инструмента: управление пользовательским Chrome было остановлено, поскольку инструмент не смог надёжно определить URL. Последующие действия через него не выполнялись; результат сохранён по имеющимся наблюдениям. Проверки установки и повторного запуска не завершены. Наличие source JSON не означает, что категория поддержана расширением.

Маршрут: https://www.kufar.by/ain/create → Выбрать категорию → Недвижимость → Дома, дачи, коттеджи. После выбора заголовок категории «Дома, агроусадьбы, коттеджи». category="1020" подтверждён справочником категории из ответа формы. UI показал название, адрес, фото (disabled до входа), описание и цену. Переключателя сделки и характеристик дома в этой сессии не было; ни пустая форма, ни её метаданные не доказывают успешное открытие let.
Использован ответ bootstrap, который запросила форма при выборе недвижимости, секция ad_metadata.parameters: базовое правило {}, правило category=1020, далее category=1020/type=let и региональные правила. Фильтры поиска не использовались. Метаданные контактных полей отмечены как непроверенные после входа.
Разрешённый контекст: category="1020", type="let", house_rent_period="10" (Долгосрочная), целый Дом/Дача. Часть дома, размещение на сутки, гостиница и база отдыха не являются целевой ветвью. Присутствующие старые условные refs для house_rent_period="1" не включены: такого варианта нет в актуальном списке аренды. Нельзя подменить его значением "10" и перенести суточные условия.
Дедупликация по name: size_area refs[818] с диапазонным набором переопределён refs[1461] формы let с v_float; price refs[1592] переопределён refs[5856] «Цена за месяц». Для Минской области region="5": country_direction refs[801] → refs[1498] с v_single; distance_ringway refs[800] → refs[1499] (числовой ввод). Условия region сохранены, направление не выдаётся за поле всех адресов. Ветвь не проверялась вводом адреса.
Примеры: валюта р. = строка "BYR", $ = "USD", € = "EUR". house_rent_period Долгосрочная = строка "10"; re_water Колодец = строка "10" — одинаковый код в другом поле означает другое. v_float имеет приоритет над общим metadata.type=int для площадей. Булевые metadata с кодами "0"/"1" сохранены как enum, чтобы не потерять строковое представление. Числовые пределы из общих input min/max не перенесены в непроверенную ветвь let.
Все options_complete=false: значения взяты из доставленного справочника, но конечный список каждой ветви в UI не проверен. Состав values сохранён полностью; отсутствие готового binding не означает неизвестность самих кодов. Для area варианты не включены: нет подтверждённого выбора региона и адреса. Удалять поле по отсутствию в неполном UI нельзя.
