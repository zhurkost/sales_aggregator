Примеры нативных кодов: plot.water «нет» = число 0, «водопровод» = число 11; termsOfDeal.currency BYN = строка "933", USD = "840", EUR = "978". Коды и типы не нормализованы под другую площадку. Название apartment.* здесь нативное имя поля формы дома, а не признак ошибочного копирования квартиры.
Обязательность numeric/text взята из props required, а не input.required: React-компонент может рисовать обязательную метку при required=false на DOM input. Где факта нет, required=null. Пределы min/max и decimals взяты из props конкретного поля. Значения 0/false не удалены.
Адресный словарь частичный: доступны 6 стартовых городов в props; зависимые улицы/номера, сельсовет/направление/расстояние, варианты без улицы, карта и итоговый geocoder payload не проверены. Кэшированные улицы не выдаются за варианты текущего выбранного города.
Оба фото-поля сохранены. UI сообщает JPG/PNG и 20 МБ, DOM accept содержит также GIF — GIF не объявлен поддержанным. Для фото бесплатной ветви max_items=20; 50 со Спецпредложением не распространяются на неё. Планировка: один файл по multiple=false; иные лимиты не перенесены с обычных фото. Правило о реальных фото не заменяет наблюдение required на форме.
Заголовок, подробное описание, YouTube и 3D помечены платным доступом. Не выдумывается поле «пакет» для when: доступность по аккаунту/подписке остаётся условием из отчёта и причиной needs_review.
