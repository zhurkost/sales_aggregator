Дополнительная проверка Автопоста — 2026-11-08

Только тестирование: 11:06:22–11:36:36 UTC, более 30 минут.
До окончания интервала изменялись только тесты и диагностический стенд.

Подтверждённая ошибка:
Realt отмечал фотографии перенесёнными сразу после назначения input.files.
В живой форме продажи HTTP 503 на загрузке оставлял 0 принятых фото,
при частичном отказе — 1 из 2. В аренде полный отказ оставлял 0 из 2.
Во всех случаях расширение считало фото заполненными и не показывало проблему.
Отказ имитировался только перехватом загрузочного запроса в тестовом браузере.
Приложение, API, расширение и остальные запросы площадки были настоящими.

Исправление:
В browser_realt.json обеих категорий добавлен счётчик принятых файлов:
input[type="hidden"][name^="media.photos."][name$=".uuid"][value]:not([value=""])
Используется существующий механизм previewSelector расширения.
Пустые UUID и выбранные в input файлы не означают успешную загрузку.
Уже присутствующие принятые фото сохраняются; новые не добавляются поверх них.
Версия расширения остаётся 0.9.22: изменение находится в данных категории.
