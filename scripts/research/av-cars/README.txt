Подключения к production и common/mapping в этом этапе нет.

ЗАПУСК ПОЛЬЗОВАТЕЛЕМ
Сборщик — отдельное расширение Chrome, не замена Автопоста.
Инструкция: RUN.txt. HAR читается локально; только «Начать / продолжить»
инициирует сетевой обход. Результат av-research-result.json содержит схему,
binding, отчёт и checkpoint. Обход может занять много часов и больше.

СТРУКТУРА
Марка.options -> choice.childOptions моделей -> choice.childOptions поколений.
Область.options -> choice.childOptions городов.
model/generation/place_city — поля с parent_option_id и options=[].
Другие справочники — плоские options; комплектация — multi_enum.
Год — integer. По согласованию пользователя годы перебираются только в памяти,
чтобы собрать все поколения. Списки годов,
диапазоны и выбранные годы не сохраняются даже в checkpoint.
Незавершённая модель после остановки поэтому проходится заново.
Контексты остальных полей, required/visible/disabled сохраняются в evidence.
year_filtered обозначает фильтрацию по году, не сохраняя сам год:
экспорт не позволяет восстановить применимость варианта к конкретному году.
Поколения дедуплицируются по нативному коду в пределах модели.
Коды берутся из intValue/stringValue/boolValue с сохранением типа;
schema id не подставляется вместо selectable value.
Неизвестный код в основе — null. Локальные ID сохраняются при однозначном
совпадении названия в том же родительском контексте.

ОБХОД И ПОЛНОТА
GET offer-form -> used condition -> валюты/обмен -> области/города ->
марки/модели -> все годы модели в памяти -> объединение поколений.
Кузова/коробки/двигатели/приводы читаются из начального ответа плоскими списками.
Выбор технических вариантов не запрашивается: модификации исключены заданием.
Новые варианты модификаций не сохраняются, старые остаются историческими;
options_complete для модификаций всегда false.
Зависимые ответы читаются через POST offer-form/update.
Нет вызовов draft/check/publish, платных пакетов или изменения аккаунта.
Минимальное тело запроса содержит контекст выбора без личных полей.
Совместимость этого тела и доступа из расширения требует первого живого запуска.
Отдельный PUT draft виден в HAR; сборщик его не вызывает. Отсутствие любых
побочных эффектов самого update нельзя доказать только журналом HAR.
Версия 0.4.0: интервал настраивается в UI, по умолчанию 20 мс, до 50 последовательных запросов/сек.
Фактическое ускорение ограничено временем ответа; requestsPerSecond виден в UI.
Прежний формат state version=1 и storage avResearch сохранены; добавлен импорт
av-research-result.json. Годы не сохраняются, незавершённая модель повторяется.
current и последние 100 событий activity хранят марку/модель/этап без годов.
Журнал виден в UI и консоли; старые checkpoint без этих свойств поддерживаются.
Проверка обновления: node --test scripts/research/av-cars/*.test.mjs scripts/research/shared/*.test.mjs
При отказе, таймауте или неожиданной схеме
сбор останавливается с частичным результатом, без автоматических повторов.
Checkpoint — после модели, области и управляющего варианта. Готовые модели
при продолжении пропускаются. Для нового снимка каталога нужна чистая установка
сборщика: текущий checkpoint предназначен для продолжения одного исследования.
complete ставится после прохода текущего объёма без модификаций;
browser binding не меняет статус.

ИСХОДНИКИ
seed.mjs — воспроизводимая основа из старых материалов и видео.
core.mjs — разбор HAR, очистка, обход с внедрённым транспортом и формирование
результатов. Импорт модуля не выполняет запросов.
import-har.mjs — офлайн-обогащение из сохранённого HAR.
extension/ — интерфейс запуска и ограниченный транспорт.
package.mjs — сборка в outputs/av-research-collector.

Команды из корня проекта, Node.js без сторонних пакетов:
  node --test scripts/research/av-cars/*.test.mjs
  node scripts/research/av-cars/seed.mjs
  node scripts/research/av-cars/import-har.mjs <local.har> [output-directory]
  node scripts/research/av-cars/package.mjs
По умолчанию seed и import-har пишут в work/av-seed и work/av-har-research;
текущий результат не перезаписывается без явного выходного каталога.

ИСТОЧНИКИ И ПРИВАТНОСТЬ
В data/parsing/cars_used_sale/evidence/:
av-historical-recovery.json — старые метаданные;
av-video-observations.json — расшифровка пользовательского видео;
av-network-observations.json и av-live-network-readonly.json — ранние наблюдения
до получения HAR; их неполнота не описывает текущее состояние сборщика;
av-catalog-source.json — очищенные ответы, контексты, покрытие и SHA256 HAR.
Raw HAR остаётся локальным источником вне репозитория и архива расширения.
x-api-key читается в память и передаётся только web-api.av.by, без редиректов.
Он не входит в storage/export. Cookies, Authorization, выбранные личные значения,
VIN, фотографии, advert и formState не извлекаются в результат.

ОБНОВЛЕНИЕ 0.4.0
Поле «Интервал запросов, мс» доступно до и во время обхода.
20 мс — значение по умолчанию, 100 мс — прежнее, 0 — без дополнительной задержки.
Настройка сохраняется отдельно для каждого расширения и не меняет checkpoint.
Это минимальный интервал между началами последовательных запросов,
а не гарантия скорости: учитываются ответ сервера и сохранение данных.
