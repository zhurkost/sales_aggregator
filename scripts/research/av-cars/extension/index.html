Справочники av.by

Полный обход: марки → модели → поколения; области → города. Остальные варианты — плоские списки. Годы используются только в памяти.

Выбери свой av-form.har. Ключ API читается из него только в память и не попадает в сохранённый результат.

HAR не выбран. Запросы не выполняются.

Версия 0.4.0 · настраиваемый интервал между началами запросов. Фактическая скорость зависит от ответов сервера.

20 мс по умолчанию (до 50 запросов/сек). 100 мс — прежняя скорость. 0 — без дополнительной задержки. Запросы последовательные; ответ сервера может занимать больше времени. Настройку можно менять во время сбора.

Модификации не собираются. Ранее сохранённые варианты не удаляются; новых запросов и вариантов для этого поля нет.

Кузова, коробки, двигатели и приводы приходят в начальном ответе; их сочетания не перебираются. Собираются марки, модели и поколения, а также география и остальные справочники. Годы только в памяти. Не закрывай вкладку и не переводи компьютер в сон; незавершённая модель при продолжении повторяется.

Используются только GET offer-form и POST offer-form/update. Запросов сохранения черновика, публикации, оплаты и изменения аккаунта нет. Если сервер откажет или ответ изменится, сбор остановится с причиной.
